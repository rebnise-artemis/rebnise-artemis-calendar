レブナイズ・アルテミス 試合カレンダー

シーズン全体をGoogleカレンダーに入れる

  • 全試合がまとめて入ります
  • パソコンで1回設定すれば、スマートフォンのGoogleカレンダーアプリにも表示されます

どちらの方法もパソコンから行ってください。GoogleカレンダーのスマートフォンアプリにはURLで追加する機能もインポート機能もありません（Googleの仕様です）。

方法1: URLで購読するおすすめ

日程や会場が変わったとき、自動で反映されます。

  1. パソコンのブラウザでGoogleカレンダーを開く
  2. 左側の「他のカレンダー」の＋を押す
  3. 「URLで追加」を選ぶ
  4. 上のURLを貼り付けて「カレンダーを追加」を押す

反映のタイミングはGoogle側が決めており、最初に表示されるまで1日以上かかることがあります。

方法2: ファイルを取り込む

すぐに全部入ります。ただし日程が変わったときは、取り込み直しが必要です。

ファイルをダウンロード
  1. 上のボタンでファイルをダウンロードする
  2. パソコンのブラウザでGoogleカレンダーを開く
  3. 右上の歯車から「設定」を開く
  4. 左メニューの「インポート / エクスポート」を選ぶ
  5. ダウンロードしたファイルと追加先のカレンダーを選び、「インポート」を押す
